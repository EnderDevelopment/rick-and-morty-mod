# Rick and Morty Mod

Add Rick and Morty-themed armor and abilities to Minecraft Bedrock Edition.

## Features

- **Evil Morty Helmet**: Equip the iconic Evil Morty helmet from Rick and Morty.
- **Energy Shield**: When the helmet is equipped, gain an energy shield that provides resistance to damage.

## Requirements

- Minecraft Bedrock Edition (version 1.20.0 or later)

## Installation

1. Download the mod files.
2. Place the `BP` folder in your Minecraft Bedrock Edition addons folder.
3. Enable the addon in Minecraft settings.

## Usage

1. Craft or obtain the Evil Morty helmet.
2. Equip the helmet to gain the energy shield effect.

## Configuration

No additional configuration is required. The mod is ready to use out of the box.
